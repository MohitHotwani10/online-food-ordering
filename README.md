# FoodExpress - Online Food Ordering System

FoodExpress is an Online Food Ordering System developed as an ASD&D mini project.

## Features

- User Registration and Login
- Secure Password Hashing
- Food Menu
- Shopping Cart
- Checkout
- Order History
- Order Status Tracking
- Admin Dashboard
- Food Management
- Order Management

## Technologies

- Python
- Flask
- Flask-SQLAlchemy
- HTML
- CSS
- Bootstrap
- SQLite

## DevOps Tools

This project demonstrates:

- Git and GitHub
- Docker
- Docker Compose
- Jenkins
- Jira
- Prometheus
- AWS
- Terraform
